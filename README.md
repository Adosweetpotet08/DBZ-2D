DragonBall 2D

A retro-inspired 2D fighting game built using HTML, CSS, and JavaScript.

This project is a personal game development project created and developed on an Android phone using Acode. It features pixel-art-inspired fighters, real-time combat, attack animations, hit reactions, and mobile-friendly controls.

🎮 About the Game

DragonBall 2D is a browser-based fighting game inspired by classic arcade and handheld fighting games. The goal is to create a simple but satisfying fighting experience with responsive controls, animated characters, and engaging combat mechanics.

The game is developed using the HTML Canvas API and JavaScript, without relying on a full game engine.

✨ Current Features

- Pixel-art-inspired character sprites
- Animated fighting and idle stances
- Player movement and jumping
- Keyboard and touchscreen controls
- Basic melee combat
- Health bars and damage calculation
- Three-hit combo tracking
- Screen shake on successful attacks
- Enemy AI movement and attacks
- Attack wind-up and punch animations
- Hit-stun mechanics
- Knockback physics
- Character hurt and recoil animations
